## 简介

Duskhaven Studio 是一款专为魔兽世界（World of Warcraft）私服 Duskhaven 设计的游戏内运镜工具。它允许你自由控制游戏镜头、创建复杂的镜头路径动画，并将最终成果导出为高质量的 MP4 视频。支持从魔兽世界 Alpha 版到 3.3.5a（巫妖王之怒）等多个客户端版本。

---

## 核心功能

- **自由观察者镜头** — 脱离玩家角色，在游戏世界中自由飞行，从任意角度观察场景。
- **运镜编辑器** — 通过快捷键捕捉路径点，构建完整的镜头运动轨迹。支持自定义运镜时长、缓动曲线和无限循环播放。
- **视频导出** — 内置录制引擎，直接捕获魔兽世界游戏窗口画面，裁剪后通过 FFmpeg 转码为高质量 MP4 视频。
- **环境控制** — 实时调整游戏内时间（小时/分钟）和渲染标志（Render Flags），精确控制场景光照和渲染效果。
- **自定义快捷键** — 所有操作均支持自定义快捷键绑定，适配个人工作流。

## 安装方式

### 方式一：下载发布版本（推荐）

从 [Releases](https://github.com/leewheel/Duskhaven-Studio/releases) 页面下载最新的安装包（`.exe`），双击安装即可。

### 方式二：从源码构建

**环境要求：**
- Node.js >= 22
- npm >= 8

```bash
# 克隆仓库
git clone https://github.com/leewheel/Duskhaven-Studio.git
cd Duskhaven-Studio

# 安装依赖
npm install

# 开发模式运行
npm run dev

# 打包构建（Windows）
npm run dist:win
```

## 使用指南

### 1. 启动与连接

1. 先启动魔兽世界客户端并登录游戏。
2. 以**管理员身份**运行 Duskhaven Studio（需要管理员权限才能读取游戏内存）。
3. 启动后，工具会自动检测并连接到正在运行的魔兽世界进程。

> **注意：** 如果启动时提示「核心桥接加载失败」，请尝试以管理员身份重新运行，或从 Releases 页面下载未打包版本使用。

### 2. 首页概览

启动后进入**首页**，你可以快速了解三大功能模块：

- **观察者镜头** — 进入自由镜头控制
- **环境控制** — 调整时间和渲染设置
- **工作室设置** — 管理快捷键和其他偏好

### 3. 观察者模式（Spectate）

点击左侧导航栏的「**观察者**」或首页的「**打开观察者**」进入。

#### 3.1 启用观察者

在右侧面板中勾选「**切换观察者模式**」（默认快捷键 `F3`），镜头将脱离玩家角色，进入自由飞行状态。

- 使用鼠标控制镜头方向
- 使用 WASD 键在场景中移动
- 「**镜头位置 (X/Y/Z)**」实时显示当前坐标，可直接输入数值精确跳转
- 「**偏航角**」和「**俯仰角**」显示当前镜头朝向（只读）
- 「**观察者移动速度**」可调整飞行速度（0.01 ~ 1.9）
- 「**启用碰撞检测**」可防止镜头穿墙（部分客户端版本支持）

#### 3.2 运镜编辑器

点击顶部的「**运镜编辑器**」选项卡进入。

**创建运镜：**
1. 启用观察者模式后，将镜头移动到想要的起始位置。
2. 按下「**添加路径点**」快捷键（默认 `F4`）记录当前镜头位置。
3. 移动镜头到下一个位置，再次按下快捷键添加路径点。
4. 重复以上步骤，构建完整路径。
5. 按下「**播放**」快捷键（默认 `F5`）预览运镜效果。

**编辑器设置：**
- **运镜时长** — 设置整个运镜从开始到结束的总秒数（默认 10 秒）
- **缓动（Easing）** — 选择缓动曲线类型，控制镜头运动的加速度变化：
  - `Power0` ~ `Power4` — 不同程度的加速/减速
  - `Bounce` — 弹跳效果
  - `Back` — 回弹效果
  - `Elastic` — 弹性效果
  - `Circ`、`Expo`、`Sine` — 圆形/指数/正弦缓动
  - 可搭配子类型（`easeIn`、`easeOut`、`easeInOut`）精确控制
- **无限循环播放** — 勾选后运镜会不断重复播放

**保存与加载：**
- 点击运镜编辑器右上角的「**保存**」将当前运镜导出为 JSON 文件
- 点击「**加载**」导入之前保存的运镜配置

> 可参考文档中的 [Ease Visualizer](https://greensock.com/docs/v2/Easing) 预览不同缓动效果。

#### 3.3 运镜导出

点击顶部「**导出**」选项卡进入视频导出界面。

**导出步骤：**
1. **选择捕获源** — 点击「刷新源」自动检测正在运行的魔兽世界窗口，选中它。
2. **设置时长** — 确认运镜时长（秒），该时长应与运镜编辑器中的设置一致。
3. **裁剪画面**（可选）— 先点击「录制」生成预览，然后点击「选择裁剪区域」，在预览画面上拖动裁剪框选择要保留的画面区域，点击「确认裁剪」。也可以使用「使用游戏区域」自动检测并裁剪掉窗口边框。
4. **开始录制** — 点击「录制」按钮，工具会自动聚焦魔兽世界窗口并播放运镜，同时录制画面。
5. **保存导出** — 录制完成后预览效果，满意后点击「保存 MP4」选择保存路径。工具会通过 FFmpeg 将录制内容转码为高质量 MP4 视频。

> **导出提示：** 录制前请确保魔兽世界以窗口或无边框模式运行，并将游戏窗口保持在前台可见。

### 4. 环境控制

点击左侧「**环境**」进入环境设置。

#### 渲染标志（Render Flags）

渲染标志是控制魔兽世界渲染方式的底层参数，以四个十六进制字节（0x00 ~ 0xFF）表示。

- 使用上下箭头按钮逐个字节递增/递减
- 「**随机**」按钮生成随机渲染标志值（可用于探索隐藏视觉效果）
- 「**重置**」按钮恢复默认渲染标志
- 「**复制**」按钮将当前渲染标志值复制到剪贴板

> **⚠️ 警告：** 修改渲染标志值可能导致客户端渲染异常甚至崩溃，尤其是 Alpha 到 3.x 版本之间。建议在修改前退出重要副本或区域。

#### 时间控制

- 勾选「**启用时间控制**」后，游戏内光照会锁定为你设定的时间
- 拖动「**时间（小时）**」和「**时间（分钟）**」滑块精确调整
- 实时显示当前设置的时间（格式：时:分）

### 5. 工作室设置

点击左侧「**设置**」进入。

#### 窗口设置

- **窗口置顶显示** — 勾选后 Duskhaven Studio 窗口始终保持在最前，方便在游戏时操作

#### 快捷键设置

所有操作均可自定义快捷键：

| 操作 | 默认快捷键 | 说明 |
|------|-----------|------|
| 切换观察者 | `F3` | 进入/退出自由镜头模式 |
| 添加路径点 | `F4` | 将当前镜头位置记录为路径点 |
| 播放 | `F5` | 播放/停止运镜 |
| 清除路径点 | `F6` | 清除所有已添加的路径点 |

- 点击任意快捷键按钮，按钮文字变为「按下按键...」后，按下你想要绑定的新按键即可完成设置。
- 配置自动保存在用户目录下，下次启动时自动加载。

## 常见问题

### Q: 启动后提示「核心桥接加载失败」？

以**管理员身份**运行 Duskhaven Studio。如果问题依然存在，请尝试从 Releases 页面下载未打包版本（unpacked build）直接运行。

### Q: 导出页面无法检测到魔兽世界窗口？

- 确保魔兽世界以**窗口模式**或**无边框窗口模式**运行（不支持全屏模式）
- 点击「刷新源」重新检测
- 确保魔兽世界在 Duskhaven Studio 启动**之前**已经打开

### Q: 导出的视频画面不完整或包含窗口边框？

使用导出页面的「**选择裁剪区域**」功能手动调整裁剪边界，或点击「**使用游戏区域**」自动检测并移除窗口边框。

### Q: 观察者模式下镜头移动不了？

- 确认已勾选「切换观察者模式」，状态栏显示绿色圆点表示已激活
- 确保魔兽世界窗口处于前台（Alt+Tab 切换到游戏窗口）

### Q: 修改渲染标志后游戏画面异常？

点击环境页面中的「**重置**」按钮恢复默认渲染标志值。

## 技术栈

- **前端框架** — Vue.js 2.6 + Vue Router + Vuex
- **桌面框架** — Electron 19
- **UI 组件库** — Bulma 0.8
- **动画引擎** — GSAP 3（GreenSock）
- **视频编码** — FFmpeg（通过 ffmpeg-static）
- **原生交互** — Koffi（FFI 绑定）+ Win32 API
