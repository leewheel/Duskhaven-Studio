## Key Features 🎉

* Build complex cinematic scenes with it's built-in editor to set waypoints with keybinds.
* Duskhaven Specific built-in video export to handle the recording process and spitting out your cinematic as an MP4.
* Full control of the environment by being able to modify day and time.
* Render flag customization! (It's random and likely useless for most people lol)

## How To Install

Build or run the project locally from this repository.

Download the setup from the releases section in this repo.
